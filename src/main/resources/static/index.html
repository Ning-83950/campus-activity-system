校园活动报名系统

这是一个基于 Spring Boot + MyBatis-Plus + H2 的校园活动报名后端服务 Demo。

技术栈：Spring Boot 2.2.5 / MyBatis-Plus / H2 / JPA / Druid

部署平台：Railway

源码：GitHub

测试账号：admin / 123456

说明：登录接口需要 RSA 加密，浏览器直接访问以下状态接口会返回"用户未登录"，这是预期行为。

可用接口示例

GET /api/user/state — 当前登录状态
POST /api/user/login — 登录（需 RSA 加密密码）
