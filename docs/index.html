Core Features

核心功能

从活动发布到签到闭环，覆盖校园活动管理的全流程

📋

活动管理

教师发布/编辑/删除活动，支持封面图上传、分类管理、审核流程，完整活动生命周期管理

📝

在线报名

学生浏览活动并在线报名/退报，系统自动校验人数上限与截止时间，支持报名审核机制

📱

二维码签到

每个活动自动生成专属签到二维码，学生手机扫码即可签到，支持手动签到补录

📄

PDF 证书

签到成功后自动生成 PDF 参与证明，包含活动名称、时间、地点等完整信息，支持一键下载

🔥

热度排行

多维度热度算法：浏览×1 + 点赞×3 + 收藏×5 + 评论×2 + 报名×4 + 签到×6，实时 TOP N 排行

📬

通知系统

活动发布/审核/报名/签到等关键节点自动推送站内信 + 邮件通知，支持群发消息给已报名学生

功能亮点

不止于 CRUD，这些设计让系统更实用

01

双 ORM 架构

MyBatis Plus 处理复杂查询 + Spring Data JPA 处理简单 CRUD，灵活高效

02

Redis Token 管理

基于 Redis 的 Token 会话管理，支持登出失效、过期自动清理

03

WebSocket 实时推送

报名状态变更、新通知等通过 WebSocket 实时推送到前端

04

前后端分离

Vue.js + Element UI 前端独立部署，Spring Boot 纯 API 后端，架构清晰

05

数据可视化

ECharts 驱动的活动统计图表，直观展示报名趋势与签到率

06

Excel 导入导出

Apache POI 实现报名名单、签到记录等数据的 Excel 批量导入导出
